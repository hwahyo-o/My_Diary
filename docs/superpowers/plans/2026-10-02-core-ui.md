# Core UI Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: use test-driven development and verification before completion.

**Goal:** Implement the MVP Core UI foundation for T28–T33: onboarding/unlock surfaces, protected five-tab app shell, Home dashboard, transaction entry sheet, Calendar, Stats, Assets, and Settings route skeletons.

**Architecture:** React components remain presentation/orchestration only. Financial numbers arrive through immutable ViewModels; UI must not import analytics selectors, IndexedDB repositories, or Vault crypto directly. Authentication and transaction persistence are represented by async callback ports that later app-runtime composition will connect to the existing Vault and Transaction services.

**Tech Stack:** React 19, TypeScript strict mode, Testing Library, existing CSS tokens. No router or component-library dependency is added in this tranche.

**Spec:** UI Information Architecture / Screen Flow / Design System plus MVP checklist T28–T33.

## Global Constraints

- Five protected tabs: Home / Calendar / Stats / Assets / Settings.
- Onboarding collects nickname + six-digit PIN and never displays or persists the PIN after submit.
- Unlock accepts PIN through a callback port; failure remains on the locked surface with a neutral error.
- Home shows period summary, quick add, budget, report status, top merchant, and today receipt from a supplied ViewModel.
- Transaction Entry Sheet exposes Quick and Direct tabs; both submit through the same `onSubmitTransaction` callback boundary.
- Calendar/Stats/Assets/Settings are accessible route surfaces, not finance-calculation owners.
- Bottom navigation uses semantic buttons with current-page state (`aria-current="page"`).
- Modal/sheet has an accessible dialog name, close control, Escape handling, and returns focus to the trigger.
- Main tap targets are at least 44 CSS px.
- No financial formula is duplicated in UI code.
- No IndexedDB, Vault crypto, analytics selector, or report generator imports are allowed from UI components.
